# Example Input — Restaurant Reservation App

## Raw Idea

"Quiero hacer una app de reservas para restaurantes"

## Additional Context (optional)

- Source: Idea propia / conversación informal
- Target users: Comensales urbanos (25-45 años) y restaurantes medianos que no tienen sistema de reservas digital
- Mercado: Ciudades medianas en Latinoamérica donde OpenTable/Resy no tienen presencia
- Inspiración: "Como un OpenTable pero para LATAM, más simple, y que el restaurante no pague una fortuna"
